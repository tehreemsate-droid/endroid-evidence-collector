# 🔍 Android Evidence Collector

A Python-based automated mobile evidence collection tool built using ADB for Android pentesting and security analysis.

---

## 📌 Overview

Android Evidence Collector is designed to automate the collection of forensic and security-related data from Android devices during mobile application security assessments.

This tool helps pentesters gather structured evidence such as:

- Device information
- Application metadata
- Permissions
- Exported components
- Log analysis
- Structured JSON reporting

---

## 🚀 Features

- 📱 Device information extraction
- 📦 App package analysis
- 🔐 Permission enumeration
- 🧩 Exported component review
- 📜 Logcat scanning with keyword detection
- 📊 Structured JSON report generation
- 🗂 Automatic timestamped evidence folders

---

## 🛠 Requirements

- Python 3.8+
- Android Debug Bridge (ADB)
- USB Debugging enabled on Android device
